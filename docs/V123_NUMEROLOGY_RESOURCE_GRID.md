# V123 — Canonical NR numerology and resource grid

V123 is additive. V50 and all earlier APIs remain unchanged.

Implemented:
- 15/30/60/120 kHz SCS and μ=0..3.
- 10/20/40/80 slots per 10 ms frame.
- 14 OFDM symbols per slot for the normal-CP model.
- 12 subcarriers per PRB.
- absolute slot, frame and in-frame slot indexing.
- collision-aware layer-aware slot resource grid.

This is the canonical indexing foundation for V124+; it does not replace the existing V49/V50 APIs.
