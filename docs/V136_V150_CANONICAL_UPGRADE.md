# V136-V150 Canonical NR Upgrade

This is an additive upgrade from V135. Existing V117-V135 modules remain the PHY foundations.

- V136: simultaneous shared multi-UE resource ownership/extraction boundary.
- V137: time-frequency DM-RS interpolation boundary.
- V138: 14-symbol full-slot resource execution.
- V139: deterministic PHY scrambling boundary.
- V140: coding-chain coverage contract for TB CRC, segmentation, LDPC, rate matching and RV.
- V141: HARQ soft combining.
- V142: SINR-to-CQI/MCS link adaptation.
- V143: multi-antenna rank/conditioning boundary.
- V144: TDL/CDL spatial-channel boundary.
- V145: mobility/Doppler state.
- V146: PRACH/random-access state machine.
- V147: PDCCH/CCE candidate allocation.
- V148: RRC/NAS UE state.
- V149: end-to-end UE orchestration.
- V150: deterministic validation gate.

Scope: these versions are canonical link/system-level integration components. They do not by themselves establish full 3GPP bit-exact conformance. Existing V118/V120/V121 remain the authoritative channel foundations and V82-V91 remain the coding/PHY foundations.
