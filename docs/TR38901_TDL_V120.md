# V120 TR 38.901 TDL channel upgrade

V120 replaces the project-specific TDL-A through TDL-E delay/power scaffolding with the TDL-A..E tables in TR 38.901 Section 7.7.2, adds delay scaling from Section 7.7.3, and implements the specified Ricean first-tap handling for TDL-D/E.

The existing canonical spatial engine remains the waveform/MIMO backend. This is a link-level TDL implementation; full TR 38.901 stochastic spatial generation, antenna patterns, angular statistics, and CDL-derived spatial filtering remain separate work.
