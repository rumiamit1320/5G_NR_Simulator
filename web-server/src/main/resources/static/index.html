Constellation

TX / RX samples
TXRX
How to read it

Each point is a complex QAM symbol. The horizontal axis is the in-phase (I) component and the vertical axis is the quadrature (Q) component. TX points are ideal symbols; RX points include channel and noise effects. Tight RX clusters mean low EVM and usually lower BER.

How to read it

Time runs left-to-right across OFDM symbols and frequency runs vertically through subcarriers/PRBs. Data REs carry payload, while control and reference signals reserve known resources for scheduling, channel estimation and synchronization. The displayed pattern is a teaching visualization; numerical PHY results come from the Kotlin reference engine.

PHY pipeline

V3 → V18 reference outputs
Bits→CRC→LDPC / Polar→Rate matching→Scrambling→QAM→Layer mapping→OFDM→MIMO channel→Equalization→Decode→Bits
LAYERSTATEREFERENCE RESULT
Concept

The transmitter converts bits into a waveform through coding, modulation and OFDM. The channel distorts that waveform. The receiver estimates the channel, equalizes the received symbols, demodulates and decodes them. The V3–V18 rows expose the existing reference-engine stages rather than replacing them with browser approximations.

05

MIMO / CSI / channel

V14–V18
Concept

MIMO uses multiple transmit and receive antennas to create spatial diversity or multiplexing. CSI describes the channel matrix seen by the receiver. Rank indicates how many independent spatial layers can be supported. MMSE balances noise enhancement against interference; ZF suppresses interference more aggressively but can amplify noise when the channel is ill-conditioned.

SNR sweep concept

What this graph means

As SNR increases, the received signal becomes stronger relative to noise. BER normally falls while throughput and usable modulation order rise until another bottleneck becomes dominant. The curve is illustrative, not a second measurement engine; use RUN SIMULATION to obtain the actual point at the current SNR.

Spatial layers concept

What this graph means

More MIMO layers can increase peak throughput because several independent streams are transmitted simultaneously. The practical limit is the channel rank, antenna configuration, SNR and receiver quality. A 4×4 array does not guarantee four useful layers.

Integrated system stack

V19–V30 + V31–V60 regression
Concept

PHY provides the radio link, while MAC scheduling, RLC segmentation/reassembly, PDCP ordering, RRC/NAS signaling, 5G Core sessions, mobility, beam management and transport networking build the end-to-end system. The regression suite exercises these layers without deleting or rewriting the existing Kotlin modules.
